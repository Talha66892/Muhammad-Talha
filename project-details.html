Portfolio project

Personal Profile Website

This is the website I am developing to introduce myself and support my search for a software engineering placement.

Purpose

The aim of the website is to give placement providers a simple way to learn about my studies, interests and current development goals. It brings this information together in one place and gives me a starting point for adding future work to my portfolio.

How I am building it

I am using HTML to organise the pages, CSS to control the layout and appearance, and JavaScript for the contact form interaction. I am keeping the code in separate files so that the structure, styling and behaviour are easier to follow.

I am using GitHub for version control so that changes can be saved as the website develops.

Accessibility and usability

I have included page headings, labelled navigation, text alternatives for meaningful images, form labels and visible keyboard focus styles. I am also checking the pages with the WAVE browser extension and will use the results to make improvements before submitting the site.

I am reviewing the design against Nielsen's usability heuristics as part of the assessment. The final evaluation will be based on the completed website.

What this work is helping me learn

Developing this site is giving me practice in planning a small website, organising files, styling pages and adding basic interaction. It is also helping me think about accessibility and usability while building, rather than treating them as checks to consider only at the end.
