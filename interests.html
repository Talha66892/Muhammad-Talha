What I enjoy learning

Technical Interests

These are some areas of software engineering that I would like to develop further during my course and placement.

Software Development

I am interested in software development because it combines logical thinking with practical problem solving. I like the idea of taking a problem, planning a solution and turning it into an application that people can use.

I want to improve my programming skills and understand how developers write code that is clear, reliable and easy to maintain. I am also interested in learning how testing and feedback can help improve a software project.

Web Development

Web development interests me because it allows me to create websites and interactive services that can be accessed on different devices. I enjoy learning how HTML, CSS and JavaScript work together to present information and make a website useful.

I would like to gain more experience in building responsive websites and making sure that people can use them easily, including people who use a keyboard or assistive technology.
