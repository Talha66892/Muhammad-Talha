MUHAMMAD TALHA - PROFILE WEBSITE

This is a multi-page personal profile website built with HTML, CSS and
JavaScript.

Pages:
- index.html: About Me
- interests.html: Technical Interests
- portfolio.html: Portfolio
- project-details.html: Project Details
- development.html: Learning Journey
- contact.html: Contact Me

Open index.html in a web browser to view the site. The contact form is a
front-end demonstration and does not send or store messages.

Project files:
- style.css: shared page layout, responsive styles and form/dialog styles
- script.js: contact form validation and portfolio dialog behaviour
- images/: images used by the pages
